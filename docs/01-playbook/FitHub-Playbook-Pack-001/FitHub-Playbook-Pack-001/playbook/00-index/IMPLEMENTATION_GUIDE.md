# Implementation Guide

Antes de implementar qualquer funcionalidade:

1. Leia a Knowledge Base.
2. Leia o Playbook do domínio.
3. Respeite os ADRs.
4. Nunca invente regras de negócio.
5. Caso exista dúvida, registre uma decisão antes de codificar.

Ordem recomendada:

Use Cases
→ Domain Model
→ APIs
→ Persistência
→ Testes
→ Código
