# Decisões Consolidadas

NUT-001: Nutrição é um domínio independente.
NUT-002: O profissional cria o plano alimentar.
NUT-003: O paciente visualiza o plano alimentar.
NUT-004: O domínio deve evoluir futuramente para recomendações por IA (fora do MVP).
NUT-005: O MVP prioriza cadastro e acompanhamento do plano alimentar.
