# Decisões Consolidadas

CAT-001: O catálogo é um domínio independente.
CAT-002: Exercícios são reutilizados pelos treinos.
CAT-003: Cada exercício pode possuir imagem, GIF e vídeo.
CAT-004: No MVP a mídia será armazenada por URL.
CAT-005: CDN própria poderá ser adotada futuramente.
CAT-006: Exercícios poderão possuir alternativas.
CAT-007: Internacionalização ficará para versões futuras.
